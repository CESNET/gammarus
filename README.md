# Grammarus

Application designed to serve as a client for interacting with Reconfigurable Optical Add-Drop Multiplexer (ROADM) devices through RESTCONF protocols. 
This application is tailored to meet the needs of network engineers and administrators managing optical networking infrastructure, offering a seamless and intuitive interface for the configuration and monitoring of ROADM devices.

## Setup development

Clone this repo locally and install dependencies with `npm install`.

Then you can start by running `npm run dev`. This will start local development server on port **5173**.
